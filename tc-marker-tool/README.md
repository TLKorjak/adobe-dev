# TC Markers — moved

This tool now lives in its own repo: [`~/Documents/Github/tc-markers`](../../tc-markers)
(published as **D-Markers**, `Promots/tc-markers` on GitHub). That repo's version has

it works, loading it in UDT, and packaging.
